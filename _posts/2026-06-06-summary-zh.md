## [通过 MicroPython 和 WASM 实现沙盒化 Python](https://simonwillison.net/2026/Jun/6/micropython-in-a-sandbox/#atom-everything) ⭐️ 8.0/10

Simon Willison 发布了一个名为 micropython-wasm 的 alpha 包，将 MicroPython 编译为 WebAssembly，从而在沙盒中安全执行 Python 代码。他还构建了一个 Datasette Agent 插件 datasette-agent-micropython 来演示这一方法。 这为在插件或用户自定义脚本中运行不受信任的 Python 代码提供了实用方案，而不会危及宿主应用的安全。它解决了 Python 生态中长期存在的对轻量级、依赖友好的沙盒的需求。 该沙盒施加了内存和 CPU 限制，限制了文件访问，并阻止网络连接。该 alpha 包可从 PyPI 安装，并包含针对多个平台的二进制 wheel。

rss · Simon Willison · Jun 6, 03:53

**背景**: MicroPython 是 Python 3 的精简实现，专为微控制器和嵌入式系统设计。WebAssembly (WASM) 是一种二进制指令格式，在沙盒环境中运行，非常适合安全代码执行。通过将 MicroPython 编译为 WASM，代码在隔离的运行时中运行，系统访问受限。

## [OpenAI 推出锁定模式阻止数据泄露](https://simonwillison.net/2026/Jun/5/openai-help-lockdown-mode/#atom-everything) ⭐️ 8.0/10

OpenAI 已正式为 ChatGPT 推出锁定模式，该安全功能通过限制出站网络请求来防止提示注入攻击导致的数据泄露。该功能正在向符合条件的个人账户（Free、Go、Plus、Pro）和自助式 ChatGPT Business 账户推出。 锁定模式直接解决了 LLM 系统中的关键“致命三重威胁”漏洞，通过切断数据泄露这一环节（最容易限制且不影响功能）提供确定性、非 AI 驱动的防御，不会被提示注入攻击绕过。 锁定模式并不阻止提示注入出现在处理的内容中，但会阻止可能将敏感数据传输给攻击者的出站网络请求。OpenAI 首席信息安全官 Dane Stuckey 指出，该模式并不适合所有人，因为它会牺牲部分功能和实用性，但对高风险用户很有价值。

rss · Simon Willison · Jun 5, 23:56

**背景**: 提示注入是一种网络安全利用手段，通过精心构造的输入使 LLM 忽略先前指令或泄露数据。数据泄露是指未经授权将数据从系统中传输出去。“致命三重威胁”描述了 LLM 系统同时具备访问私有数据、接触不可信内容以及数据泄露途径的情况；切断其中任何一环即可防止攻击。
