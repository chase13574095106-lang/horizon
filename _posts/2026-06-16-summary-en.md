## [China's First Domestic ArF Immersion Lithography Machine Delivered](https://news.tongji.edu.cn/info/1002/94903.htm) ⭐️ 9.0/10

In May 2025, the first domestically produced ArF immersion lithography machine, developed by He Rongming's team, was officially delivered to SMIC. It can support 7nm chip production using multiple patterning. This marks a major breakthrough for China's semiconductor industry, breaking the long-standing foreign monopoly on high-end lithography equipment. It enhances China's self-sufficiency in advanced chip manufacturing and reduces reliance on imports. The machine uses an argon fluoride (ArF) excimer laser at 193 nm wavelength and immersion technology to improve resolution. Multiple patterning is required to achieve 7nm node, which increases cost and cycle time.

telegram · zaihuapd · Jun 16, 16:34

**Background**: ArF immersion lithography uses a liquid (usually water) between the lens and wafer to increase numerical aperture, enabling finer features. Multiple patterning involves splitting a layer into multiple masks to achieve smaller nodes. The 7nm process initially relied on DUV immersion lithography with multiple patterning before EUV adoption.

## [Local LLMs Are Now Practical, But Pain Points Remain](https://vickiboykis.com/2026/06/15/running-local-models-is-good-now/) ⭐️ 8.0/10

A blog post argues that running local language models has become practical, but community comments reveal ongoing issues with speed, quantization, and tool calling. This debate matters because local LLMs offer privacy, offline access, and cost savings, but their usability directly affects adoption among developers and power users. Dense models like Qwen 27B are smart but slow, while MoE models like Gemma 26B are faster but error-prone. Quantization to 4-bit degrades tool calling performance, forcing users to trade off quality for speed.

hackernews · jfb · Jun 16, 14:36 · [Discussion](https://news.ycombinator.com/item?id=48555993)

**Background**: Quantization reduces model precision (e.g., from FP16 to INT4) to shrink memory and speed up inference, but can hurt accuracy. Tool calling allows LLMs to invoke external functions, enabling actions like web searches or code execution. Local models run on user hardware, offering privacy and no API costs.

## [Stop Using JWTs for Browser Sessions](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

A widely shared GitHub Gist argues that JSON Web Tokens (JWTs) should not be used for browser-based user sessions, citing security and revocation concerns. This debate affects how developers design authentication for web applications, potentially shifting best practices away from stateless JWTs toward traditional session-based approaches. The post links to a detailed critique by Paragon Initiative Enterprises, which highlights issues like the inability to revoke individual tokens and the complexity of secure implementation.

hackernews · dzonga · Jun 16, 16:49 · [Discussion](https://news.ycombinator.com/item?id=48558147)

**Background**: JWTs are a compact, self-contained token format used for authentication and information exchange. They are often used in stateless authentication, where the server does not need to store session data. However, because they are self-contained, revoking a JWT before its expiration requires additional infrastructure like a blacklist.

## [Export Controls on AI Models Harm US Cyber Defense](https://simonwillison.net/2026/Jun/16/fable-5-export-controls/#atom-everything) ⭐️ 8.0/10

The US government banned Anthropic's Claude Fable 5 and Mythos 5 via export controls on June 12, 2026, after researchers used the model to fix code with known vulnerabilities, which was classified as a 'jailbreak.' Security expert Kate Moussouris argues this is absurd because fixing security bugs is exactly what defenders need. This policy undermines US cyber defense by preventing AI models from helping fix security vulnerabilities, while adversaries can still use unrestricted models. It highlights a critical flaw in export control rules that conflate defensive security actions with malicious attacks. The 'jailbreak' involved asking Fable 5 to 'fix this code' containing known CVEs and deliberately planted vulnerabilities, then manually turning the output into test scripts. Kate Moussouris notes that this capability cannot be removed without making the model worse at fixing bugs and verifying patches.

rss · Simon Willison · Jun 16, 05:20

**Background**: Export controls are government regulations that restrict the transfer of certain technologies to foreign entities. In this case, the US government banned Claude Fable 5 under rules designed to prevent AI models from being used for cyber attacks. Common Vulnerabilities and Exposures (CVE) is a dictionary of publicly known security vulnerabilities. 'Jailbreaking' an AI model means bypassing its safety constraints to generate restricted content.
