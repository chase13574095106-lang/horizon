Astronomers have identified a candidate exomoon, designated CD-35 2722 b I, orbiting a brown dwarf in a binary system, potentially marking the first detection of an exomoon. If confirmed, this discovery would be a milestone in astronomy, opening a new frontier in the study of exomoons and their potential habitability, and challenging current classification of substellar objects. The candidate exomoon orbits a brown dwarf that itself orbits a primary star in the binary system CD-35 2722. The system's unusual architecture blurs the line between planet and moon, as the brown dwarf is more massive than typical planets.

hackernews · MarcoDewey · Jul 23, 14:02 · [Discussion](https://news.ycombinator.com/item?id=49021783)

**Background**: An exomoon is a natural satellite orbiting an exoplanet or other non-stellar extrasolar body. Brown dwarfs are substellar objects with masses between 13 and 80 times that of Jupiter, too small to sustain hydrogen fusion but capable of deuterium fusion. Detecting exomoons is extremely challenging due to their small size and distance; no exomoon has been confirmed to date.

## [PyPI Blocks File Uploads to Releases Older Than 14 Days](https://simonwillison.net/2026/Jul/23/seth-larson/#atom-everything) ⭐️ 8.0/10

PyPI now rejects new file uploads to releases older than 14 days, a change implemented to prevent supply-chain poisoning attacks via compromised publishing tokens or workflows. This security enhancement closes a significant attack vector in the Python package ecosystem, making it harder for attackers to inject malicious code into long-stable releases and potentially affecting millions of users who rely on PyPI. The restriction was implemented via pull request #19727 in the PyPI Warehouse repository. As of the announcement, no known abuse of this vector had occurred, but the change was made proactively because there was no technical barrier preventing such attacks.

rss · Simon Willison · Jul 23, 04:50

**Background**: Supply-chain poisoning attacks involve injecting malicious code into trusted software components, which then spreads to downstream users. PyPI, the official package repository for Python, has been a target for such attacks in the past. Publishing tokens and CI/CD workflows are common authentication methods for uploading packages; if compromised, attackers could upload malicious files to existing releases without changing version numbers.
