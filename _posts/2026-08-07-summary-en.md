## [Chinese-led team confirms existence of glueballs, new form of matter](https://mp.weixin.qq.com/s/pvyNR1lN7QPx3IrpB3WtUg) ⭐️ 9.0/10

On August 6, 2026, the BESIII collaboration at the Beijing Electron-Positron Collider announced the first experimental confirmation of glueballs, a new form of matter. After 15 years of research, they verified that the particle X(2370), discovered in 2011, has properties consistent with a glueball. This is a groundbreaking milestone in particle physics, as glueballs were predicted by the Standard Model but had never been observed in nearly 50 years of searching. Confirming their existence validates fundamental theories and opens new avenues for studying the strong force. The team measured the quantum state of X(2370) in 2024, finding its mass, production, and decay properties match glueball predictions. The latest study identified new decay modes and determined its flavor-singlet nature, confirming that X(2370) is primarily a glueball.

telegram · zaihuapd · Aug 6, 07:31

**Background**: Glueballs are hypothetical particles composed solely of gluons, the carriers of the strong force, with no valence quarks. They are predicted by the Standard Model of particle physics, but their existence had not been confirmed experimentally. The BESIII detector at the Beijing Electron-Positron Collider (BEPCII) has collected over 10 billion J/psi events, providing a unique environment to search for glueballs in particle decays.

AMD has acquired AI chip startup Taalas to boost inference performance by etching models directly into silicon. The acquisition was announced on August 6, 2026, and aims to advance compute solutions for the rapidly growing AI inference market. This move could disrupt the AI hardware landscape by offering significantly faster and cheaper inference, challenging NVIDIA's dominance. It also signals a strategic shift for AMD to differentiate in the AI inference market, potentially reshaping how AI models are deployed at scale. This contrasts with traditional AI accelerators like NVIDIA's GPUs, which rely on high-bandwidth memory (HBM) to store model weights.

## [Datasette 1.0a38 fixes SQL injection in mixed public/private setups](https://simonwillison.net/2026/Aug/6/datasette/#atom-everything) ⭐️ 8.0/10

Datasette 1.0a38 is a security patch release that fixes a SQL injection vulnerability affecting instances serving a mixture of public and private tables in the same database. The fix is also available in Datasette 0.65.3. This vulnerability could allow users with access to any public table to execute SQL injection attacks and gain read-only access to private data in the same database, posing a significant data exposure risk. The patch is crucial for administrators running such mixed-access instances, as it closes a serious security hole in a widely-used open-source tool. The vulnerability affects Datasette instances that use the Datasette permissions system to configure mixed public/private table access. Administrators are advised to disable the execute-sql permission on affected databases to prevent raw SQL queries from accessing private tables, even after applying the fix.

rss · Simon Willison · Aug 6, 18:24

**Background**: Datasette is an open-source tool for exploring and publishing data, often used to share datasets online. It includes a permissions system that allows administrators to control access to databases, tables, and queries, but by default any visitor can execute read-only SQL queries. The execute-sql permission is a specific permission that controls whether users can run arbitrary SQL queries, and disabling it is a recommended security measure for instances with private data.

## [OpenAI Launches Agent Plugins Standard on GPT-5's First Anniversary](https://9to5mac.com/2026/08/06/gpt-5-turning-one-as-openai-shares-new-agent-plugins-standard/) ⭐️ 8.0/10

On August 6, 2026, OpenAI introduced Agent Plugins, an open, vendor-neutral standard for packaging reusable AI agent components such as Agent Skills and MCP servers into portable plugins. The standard's steering committee includes Amazon, Cursor, Microsoft, OpenAI, and Vercel, and it is openly developed. This standard could significantly enhance AI agent interoperability, allowing skills and tools to be shared across different platforms, similar to how web standards enabled the modern internet. It may accelerate the adoption of AI agents by reducing fragmentation and fostering a plugin ecosystem. The Agent Plugins specification version 1.0.0 defines a shared format for Agent Skills and MCP servers, which compatible clients can discover and load consistently. The announcement coincides with GPT-5's first anniversary, during which the GPT-5 family saw multiple updates (5.1 to 5.6), and Apple integrated it into Apple Intelligence in iOS 26.

telegram · zaihuapd · Aug 7, 00:46

**Background**: Agent Plugins builds on the Model Context Protocol (MCP), an open standard introduced by Anthropic in November 2024 to standardize how AI systems integrate with external tools and data. MCP has been adopted by major AI providers, including OpenAI and Google DeepMind. The new standard aims to package MCP servers and Agent Skills into portable plugins, addressing the lack of a unified way to share and version AI agent extensions.
