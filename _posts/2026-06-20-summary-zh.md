## [我国首部 L3/L4 自动驾驶强制性国标报批](https://www.sohu.com/a/1038536454_115362) ⭐️ 9.0/10

工信部已完成《智能网联汽车自动驾驶系统安全要求》强制性国家标准报批稿，建议 2027 年 7 月 1 日实施。这是我国首部针对 L3 和 L4 级自动驾驶的强制性标准，引入了 Safety Case 安全档案机制，要求企业用“声明—论据—证据”系统性论证安全性。 该标准标志着监管从概念松绑转向安全硬约束，结束了车企靠模糊宣传抢市场的阶段，未来竞争将聚焦安全能力。短期内可能推高冗余系统和高算力芯片等成本，但长期会被技术迭代和规模效应逐步摊薄。 该标准对 L3 的人机交接和 L4 的系统自主风险处置分别提出了具体要求。目前标准处于公示期（6 月 17 日起），建议实施日期为 2027 年 7 月 1 日。

telegram · zaihuapd · Jun 20, 03:31

**背景**: 自动驾驶等级由 SAE International 定义：L3（有条件自动化）允许车辆在特定条件下自动驾驶，但需要驾驶员在系统请求时接管；L4（高度自动化）可在定义的运行设计域内无需驾驶员干预完成所有驾驶任务。Safety Case 是一种由证据支持的结构化论证，用于证明系统在特定应用和运行环境中是可接受安全的。

## [IETF 提议 HTTP QUERY 方法：带请求体的安全查询](https://httpwg.org/http-extensions/draft-ietf-httpbis-safe-method-w-body.html) ⭐️ 8.0/10

IETF HTTP 工作组正在制定一项草案，新增 HTTP QUERY 方法，允许将查询参数放在请求体中，同时保持 GET 的安全性和幂等性，便于缓存、重试和自动恢复。 该提案解决了 GET（URL 长度限制）和 POST（非幂等、不可缓存）的实际限制，可能简化 API 设计并提高 Web 应用中复杂查询的性能。 QUERY 方法定义了 Accept-Query 响应头，让服务器声明支持的查询格式；当前草案将于 2026 年 12 月到期。

telegram · zaihuapd · Jun 20, 06:28

**背景**: HTTP GET 请求受 URL 长度限制且不能携带请求体，而 POST 请求不安全且非幂等，不适合缓存和重试。提议的 QUERY 方法结合了两者的优点，允许在请求体中携带复杂查询并保持安全语义。
