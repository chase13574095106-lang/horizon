## [借助 LLM 阅读 68000 汇编，将 1993 年 Amiga 游戏移植到 Godot](https://babyloniantwins.com/blog/porting-a-1993-amiga-game-to-godot/) ⭐️ 8.0/10

一位开发者利用 LLM（Claude Fable 5）在一个晚上成功将他 1993 年用 MC68000 汇编编写的 Amiga 游戏移植到了 Godot 引擎。LLM 使用 vasm 汇编代码，并不断迭代直到二进制文件与原始文件逐字节一致，仅存在 108 字节的差异。 这展示了 LLM 在迁移遗留汇编代码方面的新颖且实用的用途，可能激发类似项目，并减少保留或现代化复古游戏所需的工作量。它凸显了 AI 理解和翻译低级代码的能力日益增强，这可能对软件考古学和游戏保存产生影响。 原始游戏于 1993 年在巴格达使用 AsmOne 构建，AsmOne 在内存中汇编，因此发布的二进制文件是运行中游戏的快照，而非干净的汇编输出，这解释了 108 字节的差异。开发者花了数周分析 LLM 的工作，并输入他 33 年的记忆、笔记和 git 仓库，文章经过一周逐行编辑。

hackernews · rabahs · Sep 3, 14:28 · [社区讨论](https://news.ycombinator.com/item?id=49550375)

**背景**: Amiga 是 20 世纪 80 年代末至 90 年代初流行的个人电脑，通常使用 MC68000 汇编进行编程以获得性能。Godot 是一个现代开源游戏引擎，支持 2D 和 3D 游戏开发。AsmOne 是 Amiga 上流行的汇编 IDE，而 vasm 是一个可移植的汇编器，可针对 68000。像 Claude 这样的 LLM 是能够理解和生成代码的 AI 模型，可协助翻译遗留代码库。

## [Polars 2.0 预发布聚焦破坏性变更与更合理的默认设置](https://pola.rs/posts/announcing-polars-2/) ⭐️ 8.0/10

Polars 已宣布 2.0 版本的预发布，这是一次以破坏性变更而非新功能为重点的重大版本升级。该版本旨在移除遗留的设计决策，并将默认设置调整为更合理的选项，例如让 Lazy API 默认使用流式引擎，以及将 maintain_order 的默认值改为 False。 此次发布意义重大，因为 Polars 是一个广泛使用的数据处理库，默认设置和 API 设计的变更将影响众多用户和下游项目。通过清理遗留决策，Polars 旨在提升长期可维护性和用户体验，并可能影响更广泛的数据生态系统。 主要变更包括 Lazy API 默认使用流式引擎，以及 maintain_order 默认改为 False，这可能会在某些操作中引入非确定性行为。团队将此次发布描述为“无聊的”，强调这不是一个功能丰富的版本，而是对过去设计选择的清理。

hackernews · komape · Sep 3, 06:59 · [社区讨论](https://news.ycombinator.com/item?id=49546753)

**背景**: Polars 是一个用 Rust 编写的 DataFrame 分析查询引擎，以其速度和效率著称。它提供 eager 和 lazy 两种 API，其中 lazy API 允许进行查询优化。2.0 版本是重大版本升级的一部分，在语义化版本控制（semver）中，这允许引入不向后兼容的破坏性变更。
