Lean is a theorem prover and functional programming language used for formalizing mathematics and verifying proofs.

## [Zhipu AI Releases GLM-5.4, First Loop Transformer for Generalized Coding](https://z.ai/blog/glm-5.4) ⭐️ 8.0/10

Zhipu AI has released GLM-5.4, its first flagship model built on a Loop Transformer architecture, aimed at 'generalized coding' that extends beyond traditional programming to areas like video production, game development, 3D modeling, and mechanical design. The model is available through Z.ai's Coding Plan, which provides API keys with access to the new model. This marks a notable architectural shift for state-of-the-art LLMs, as loop transformers reuse layers to reduce memory bandwidth bottlenecks during inference, potentially enabling more efficient scaling. The release also signals Zhipu's push toward transparent, open technical disclosure, contrasting with more closed approaches from Western labs. GLM-5.4 reportedly reaches intelligence levels comparable to 2T-3T parameter models and adds visual understanding capabilities, but users note that access requires the Coding Plan rather than the regular API plan. Community members also report that the model's 'marathon thinking' sessions can make it slow on simple tasks due to excessive self-checking.

hackernews · foohis · Nov 23, 10:06 · [Discussion](https://news.ycombinator.com/item?id=50609685)

**Background**: A loop transformer (also called a looped or recurrent-depth transformer) is a variant of the standard transformer in which a shared block of layers is applied iteratively multiple times over the same latent representation, rather than passing a token once through a tall stack of unique layers. This parameter-efficient design can reduce the need to move entire layers from memory to the chip for each token, addressing memory bandwidth as a key inference bottleneck. Zhipu AI is a Chinese AI company known for its GLM series of large language models.

## [Z.ai Releases GLM-5.4, Its First Looped Transformer Model](https://simonwillison.net/2026/Nov/23/glm-54/) ⭐️ 8.0/10

Z.ai has released GLM-5.4, its first model built on a looped transformer architecture that reuses weight-shared layers across multiple iterations to deepen reasoning without increasing parameter count. The release comes just days after Thinking Machines Lab introduced Inkling 2 Mini, another looped transformer, on November 20. This is the second looped transformer announcement in a week, suggesting the architecture is emerging as a notable trend in LLM design for improving reasoning efficiency. As a flagship model from a major Chinese AI lab, GLM-5.4 could influence how other labs approach depth versus parameter scaling. GLM-5.4 is not yet available as open weights and is currently accessible only through Z.ai's Coding Plan subscription, though its OpenAI-compatible Responses API at https://api.z.ai/api/v1 works with the coding plan key. Z.ai has published no benchmarks for the model, and Simon Willison's pelican test showed output quality comparable to GLM-5.3 rather than a dramatic leap.

rss · Simon Willison · Nov 23, 23:40

**Background**: A standard Transformer runs each layer once per forward pass, while a looped transformer runs a group of weight-shared layers for multiple iterations, refining hidden states each time. This yields a deeper effective network without adding parameters, and Thinking Machines Lab's Inkling 2 Mini similarly loops its middle layers three times per token to reason more per token. Z.ai's GLM series is a family of Chinese LLMs that has progressed through versions 5.1, 5.2, and 5.3, with earlier generations known for distinctive stylistic outputs.

## [Ladybird browser releases first alpha for macOS and Linux](https://simonwillison.net/2026/Nov/23/ladybird/) ⭐️ 8.0/10

Ladybird, an independent browser project with its own rendering engine, released its first alpha on November 23, 2026, allowing users on macOS and Linux to install it without compiling from source. The alpha includes its own HTML parser, CSS engine, layout, JavaScript, and WebAssembly implementations, while still relying on external libraries like HarfBuzz, Skia, ffmpeg, and SQLite. This is a significant milestone for browser diversity, as Ladybird is one of the few new engines built from scratch rather than forking Chromium, Gecko, or WebKit, offering a potential alternative to the dominant browser engines. Its alpha release makes the project accessible to a wider audience and could spur innovation in open web standards. Early testing shows Ladybird runs WebAssembly-based tools like ffmpeg and Pyodide, but it fails on complex service worker and web worker arrangements such as Datasette Lite due to a missing `navigator.serviceWorker.startMessages` function. The browser uses a multi-process architecture with separate processes for tabs, similar to other modern browsers.

**Background**: Ladybird is a new browser engine built from scratch, backed by a non-profit organization, and is not a fork of existing engines like Chromium, Gecko, or WebKit. It originated from the SerenityOS project, an open-source desktop operating system that includes its own web browser, and has since split off to become an independent project. The alpha release marks the first time users can install the browser without compiling it themselves.

## [Codex2api hit by supply chain attack via compromised author account](https://github.com/WormW/codex2api-incident-2026-11) ⭐️ 8.0/10

The author account of Codex2api was compromised, allowing attackers to push a malicious tag that bypassed the main branch and produced a backdoored release (v3.1.11) with authentication removed, enabling unauthenticated remote code execution. A workflow also exfiltrated 16 GitHub Actions secrets across at least 21 repositories under the same account. This is a concrete supply-chain attack that shows how a single compromised maintainer account can silently backdoor a release and leak secrets across many projects, affecting anyone who installed or updated the tool. It highlights the need for stronger account security and release integrity checks in open-source ecosystems. Users who installed or updated versions 3.1.10–3.1.12 should immediately stop using them, roll back to 3.1.9, and rotate all related secrets including GitHub tokens, SSH keys, database credentials, and DeepSeek API keys. The attack bypassed the main branch by pushing a tag directly, which triggered a release build containing the backdoor.

telegram · zaihuapd · Nov 23, 11:21

**Background**: GitHub Actions is a CI/CD service that runs workflows defined in repositories, often with access to repository secrets. Attackers who gain control of a maintainer account can push a malicious tag to trigger a release build that includes backdoored code, bypassing normal branch protections. Secrets exfiltration occurs when a workflow sends sensitive data like tokens or keys to an external server.
