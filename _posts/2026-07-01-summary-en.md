The gateway uses the HTTP 402 status code to trigger payment challenges, and at launch, payments will settle in stablecoins. Cloudflare has opened a waitlist for the service.

**Background**: The x402 protocol is an open payment protocol built on the HTTP 402 'Payment Required' status code. It allows servers to respond to unpaid requests with a challenge specifying price, asset, and network, enabling machine-to-machine micropayments. Cloudflare's gateway leverages this to monetize bot traffic without disrupting human users.

## [sing-box uTLS Chrome Fingerprint Lacks Post-Quantum Key Exchange](https://sing-box.sagernet.org/configuration/shared/tls/) ⭐️ 8.0/10

sing-box's uTLS Chrome fingerprint does not include the X25519MLKEM768 hybrid post-quantum key exchange curve, which Chrome 131+ uses as its default key exchange group, making the imitation distinguishable. The project has removed the chrome_pq fingerprint in version 1.10.0 due to incompatibility with the Reality protocol and now recommends NaiveProxy instead. This flaw undermines the effectiveness of sing-box for censorship circumvention, as advanced detection systems can identify its TLS traffic as non-browser. It highlights the ongoing challenge of perfectly mimicking browser TLS fingerprints, especially as browsers adopt post-quantum cryptography. The uTLS fingerprint module operates independently from the standard TLS engine's curve_preferences, so even if X25519MLKEM768 is listed in curve_preferences, it does not affect the uTLS ClientHello. The official documentation explicitly advises against using uTLS due to repeated fingerprint vulnerabilities and recommends NaiveProxy for stronger anti-fingerprinting capabilities.

telegram · zaihuapd · Jul 1, 07:04

**Background**: uTLS is a fork of Go's crypto/tls library that allows low-level manipulation of the TLS ClientHello to mimic browser fingerprints. Post-quantum key exchange, such as X25519MLKEM768, combines a traditional elliptic curve with a quantum-resistant KEM to protect against future quantum attacks. NaiveProxy uses Chromium's network stack to perfectly replicate browser traffic, avoiding fingerprint mismatches.

The GENIUS Act, signed into U.S. law in 2025, provides a federal regulatory framework for payment stablecoins, aiming to foster innovation while ensuring consumer protection.
