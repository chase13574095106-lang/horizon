## [Goldman Sachs Restricts Claude Code to Engineers, Removing Access for Bankers and Traders](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers) ⭐️ 8.0/10

Goldman Sachs has restricted access to Anthropic's Claude Code and Microsoft's GitHub Copilot to its approximately 12,000 engineers, pulling the AI coding tools from bankers and traders who had used them for months. The internal guidance was updated in October following a productivity-and-risk review, as reported by Bloomberg. This move highlights the challenges of deploying AI coding agents in regulated financial environments, where security, compliance, and billing risks can outweigh productivity gains. It may signal a broader trend of financial institutions re-evaluating AI tool access for non-engineering staff. Goldman's 'strats' group—software engineers who also do quant work—retains access, while the tools were previously used by traders and bankers to track client flows and build market models. The decision follows concerns about the 'lethal trifecta' of AI agents having access to sensitive data, email, and internet on primary workstations.

hackernews · TheWiggles · Nov 8, 18:16 · [Discussion](https://news.ycombinator.com/item?id=50415628)

**Background**: Claude Code is Anthropic's agentic coding tool that can edit files, run commands, and assist with software development. AI coding agents like Claude Code and GitHub Copilot are increasingly used in enterprises, but they pose security risks such as data leakage and unauthorized access, especially in finance where compliance is stringent.
