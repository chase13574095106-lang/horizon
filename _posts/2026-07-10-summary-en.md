## [QuadRF: Open-Source RF Camera Sees WiFi Through Walls](https://www.jeffgeerling.com/blog/2026/quadrf-can-spot-drones-and-see-wifi-through-my-wall/) ⭐️ 8.0/10

QuadRF, an open-source RF visualization tool based on a modular 4x4 MIMO SDR tile and Raspberry Pi 5, has been demonstrated to detect drones and map WiFi signals through walls. The project is available on Crowd Supply and GitHub, with the creator actively engaging with the community for improvements. This tool democratizes phased array technology, making advanced RF sensing accessible to hobbyists, security researchers, and educators. It has practical applications in drone detection, wireless network diagnostics, and privacy auditing, potentially raising awareness about RF surveillance capabilities. QuadRF uses a 4x4 MIMO software-defined radio tile with an open antenna architecture, powered by a Raspberry Pi 5, to function as a real-time RF camera. It color-codes detected sources by frequency and can identify the physical location of WiFi access points, wireless cameras, drones, and other transmitters.

**Background**: Software-defined radio (SDR) allows radio communication to be implemented in software rather than hardware, enabling flexible signal processing. Phased array antennas use multiple antenna elements to steer beams electronically, traditionally found in military and aerospace systems. QuadRF combines these technologies in an affordable, open-source package.
