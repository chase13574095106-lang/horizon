## [研究揭示九款对话式 AI 智能体中的广告追踪器](https://jorgegarciaherrero.com/wp-content/interactivos/20260916-Prompt-like-a-butterfly-sting-like-a-tracker-(clean).pdf) ⭐️ 8.0/10

一篇题为《Prompt like a Butterfly, Sting like a Tracker》的新论文对九款主流对话式 AI 服务的网页端和移动端部署进行了系统性隐私分析，结合静态与动态分析检测第三方广告与追踪服务（ATS），并刻画其数据流向。随附的 Hacker News 讨论（407 分、129 条评论）还揭露了具体泄露案例，例如 ChatGPT 将未完成的提示词发送至`conversation/prepare`端点，以及 Perplexity 通过基于 UUID 的 URL 暴露完整对话内容。 研究结果表明，用户常视为私密思考空间的对话式 AI 服务，实际上嵌入了与整个互联网相同的广告追踪基础设施，可能暴露提示词、写作习惯和对话历史。这关系到数亿聊天机器人用户，也给 AI 厂商带来压力，要求其在变现和投资者诉求与用户隐私预期之间取得平衡。 该分析覆盖网页端和移动端部署，并评估了同意选择、订阅层级和访问控制机制如何影响追踪行为，这意味着即便是付费用户也可能无法完全免受追踪。社区报告补充称，ChatGPT 的`conversation/prepare`端点会在用户点击发送前收到部分提示词，而 Perplexity 将 URL 中的 UUID 视为足够的隐私保护，但实际上访问该链接就会暴露整个对话。

## [Anthropic：GLM-5.3 与 Claude Mythos Preview 跨越二进制漏洞利用能力门槛](https://simonwillison.net/2026/Sep/29/anthropic-frontier-red-team/) ⭐️ 8.0/10

Anthropic 的 Frontier Red Team 在其内部二进制漏洞利用基准测试中随机抽取 100 个任务对多个模型进行评估，发现 GLM-5.3 在 4% 的试验中实现了完整的控制流劫持，Claude Mythos Preview 则为 6%。而此前的模型如 Claude Opus 4.6 和 GLM-5.2 在所有试验中均未成功，这标志着一条明确的能力门槛已被跨越。 这是一个值得关注的 AI 安全里程碑，因为它表明前沿模型开始能够自主完成端到端的二进制漏洞利用，而这项任务此前需要熟练的人类研究人员才能完成。这对网络攻防平衡有直接影响，尤其是因为 GLM-5.3 是开放权重模型，恶意行为者可以对其进行改造以削弱安全拒答机制。 该评估使用了 Anthropic 内部二进制漏洞利用基准测试中随机抽取的 100 个任务，报告的成功率绝对值仍然很低（4% 和 6%），因此这些模型距离可靠的自主漏洞开发还有很大差距。根据随附的 Telegram 摘要，GLM-5.3 在 ExploitBench 的 410 次尝试中成功了 50 次，而 Claude Mythos Preview 为 56 次；在模拟测试中，其安全防护可被简单方法绕过，成功率为 64% 至 100%。

rss · Simon Willison · Sep 29, 22:20

**背景**: 二进制漏洞利用是指寻找并滥用已编译程序中的内存破坏漏洞，使程序按照攻击者期望的方式运行。完整的控制流劫持意味着攻击者获得了程序执行路径的控制权，例如通过覆盖调用栈上的返回地址，让程序跳转到攻击者选定的代码，这类技术通常与面向返回编程（ROP）相关。Anthropic 的 Frontier Red Team 是一个对前沿 AI 系统进行压力测试的团队，旨在评估其对网络安全、国家安全和自主系统的影响。GLM-5.3 是智谱 AI（Z.ai）的旗舰开放权重模型，与 GLM-5.2 使用相同的基础模型，其能力提升完全来自后训练。

## [Cloudflare 推出面向 AI Agent 的 cf CLI，覆盖 3000 多项 API 操作](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) ⭐️ 8.0/10

Cloudflare 发布了 cf CLI 的开放测试版，这是一款由其 API Schema 自动生成的命令行工具，覆盖超过 3000 项 Cloudflare API 操作，而现有的 Wrangler 仅覆盖约 280 种操作。该工具默认以 JSON 作为输出格式，并支持命令搜索与引导式发现，明确面向开发者和 AI Agent，使其能够自动发现、执行并处理 Cloudflare API 操作。 这标志着开发者工具正开始专门为 AI Agent 而设计，因为命令行这种纯文本输入输出的界面天然适合由大语言模型驱动的自动化。如果 Agent 能通过单一工具管理 Worker、Access、WAF 甚至购买域名，这将可能重塑基础设施的配置方式以及智能体工作流与云平台的集成模式。 cf CLI 直接由 Cloudflare 的 OpenAPI Schema 生成，这也是它能实现如此广泛覆盖的原因，目前处于开放测试阶段。Cloudflare 举例说明，Agent 可以通过同一工具创建和部署 Worker、监控服务、配置 Access 与 WAF，甚至购买域名。

telegram · zaihuapd · Sep 29, 13:46

**背景**: Cloudflare 自 2022 年起就为其 API 发布了 OpenAPI Schema，这使得从单一权威来源自动生成客户端和工具成为可能。Wrangler 是 Cloudflare 现有的命令行工具，主要面向 Workers 开发者平台，但只覆盖了公司 API 的一部分。命令行界面正日益被视为 AI Agent 的理想接口，因为它完全基于文本运行，便于语言模型调用和解析。
