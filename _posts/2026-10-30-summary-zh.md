## [币安据称遭 56 亿美元黑客攻击，SAFU 基金被清空](https://arkm.com/explorer/entity/21a94755-f604-45e5-9501-6542e23005e8) ⭐️ 9.0/10

据称，币安遭遇了高达 56 亿美元的黑客攻击，其 SAFU 保险基金已被清空，而 Circle 和 Tether 已冻结了其中 24 亿美元。如果得到证实，这将是史上最大的加密货币盗窃案之一。 这一事件可能严重削弱人们对中心化交易所和整个加密生态系统的信心，尤其是币安作为交易量最大的交易所。稳定币发行方冻结数十亿美元也凸显了它们对市场日益增长的影响力。 SAFU 基金成立于 2018 年，仅持有约 10 亿美元的比特币，据称已被完全清空。被冻结的资产包括以太坊上的 9.7115 亿 USDT 和 8.23 亿 USDC，波场上的 3.1273 亿 USDT，以及以太坊上的 1.75 亿 USDT。

## [Mistral 在限制性许可下发布 Mistral Large 4 的权重](https://mistral.ai/news/mistral-large-4-oss/) ⭐️ 8.0/10

Mistral AI 发布了 Mistral Large 4（代号“Le Chonk”）的权重，这是一个拥有 1 万亿参数的多模态混合专家模型，激活参数为 520 亿，在欧洲训练完成。此次发布采用限制性许可，要求任何模型即服务（Model-as-a-Service）业务必须签订单独的商业协议，同时 Mistral 将 API 价格较预览版下调了约一半。 此次发布使 Mistral 成为欧洲领先的 AI 提供商，拥有强大的开放权重模型，可能吸引寻求数据主权和合规性的欧洲公司。然而，限制性的商业许可引发了关于其能否真正被称为“开放权重”的争论，凸显了 AI 行业中日益增长的带门槛发布趋势。 该模型总参数为 1.05 万亿，激活参数为 520 亿，配备 1.6B 视觉编码器，在恶意网络请求上的平均拒绝率达到 96.6%。许可证明确要求任何模型即服务业务必须获得单独的商业许可，API 价格现为每百万输入 token 0.7 美元和每百万输出 token 2.1 美元，分别低于之前的 1.36 美元和 4.18 美元。

hackernews · kuberwastaken · Oct 29, 14:13 · [社区讨论](https://news.ycombinator.com/item?id=50289418)

**背景**: Mistral Large 4 是一个混合专家（MoE）模型，意味着它对每个输入只激活一部分参数，从而提高效率。“开放权重”意味着训练好的模型参数可以公开下载，但与开源软件不同，许可证可以对商业使用施加限制，例如要求提供模型即服务时需签订单独协议。Mistral AI 是一家法国公司，专注于欧洲 AI 主权和企业解决方案。

## [PHP2Shell 与 Linux XFRM 漏洞链攻击攻陷 25 台服务器，包括美国政府系统](https://dreamgroup.com/blog/chained-php2shell-exploit-roots-25-servers) ⭐️ 8.0/10

一名疑似与中国有关联的攻击者利用 AI 辅助的 PHP2Shell 漏洞利用链，结合 Linux 内核 XFRM ESP-in-TCP 漏洞（CVE-2026-46300，代号“Fragnesia”），攻陷了 25 台服务器，其中包括美国政府环境中的系统，并试图攻击 Active Directory。 这一真实事件凸显了默认启用的 Linux 内核子系统（如 XFRM 和 mptcp）带来的风险，即使未使用也会扩大攻击面，并展示了如何通过链式利用 Web 和内核漏洞完全攻陷关键政府系统。 PHP2Shell 漏洞（CVE-2026-109618 和 CVE-2026-109619）影响 PHP 5.4 至 8.5 版本，允许远程代码执行；XFRM 漏洞是 ESP-in-TCP 子系统中的逻辑错误，可获取 root 权限。评论者指出利用链包含内存耗尽步骤（约 383MB），并根据 PAN-OS 设置和 SELinux 配置推测防火墙供应商是 Palo Alto Networks。

hackernews · 882542F3884314B · Oct 29, 10:42 · [社区讨论](https://news.ycombinator.com/item?id=50286987)

**背景**: PHP2Shell 指的是 PHP 中的一对高危内存安全漏洞，可导致远程代码执行，使攻击者能够控制 Web 服务器。XFRM 是 Linux 内核中用于 IPsec 转换的框架，ESP-in-TCP 功能通常默认启用，提供了潜在的本地权限提升路径。将 Web 漏洞利用与内核漏洞利用链式结合，攻击者可以先获得初始访问权限，然后提升至 root。

## [Anthropic 借助 Claude 用 Rust 重写 Messages API，CPU 用量降低 40-50%](https://latent.space/p/opus55/) ⭐️ 8.0/10

Anthropic 将其 Messages API 从 Python 单体服务迁移到 Rust，由 Claude 负责代码生成，工程师专注于系统设计和验证。重写后 CPU 用量降低约 40% 至 50%，首个 token 的响应时间缩短约 10% 至 20%。 这是一个重要的真实案例，展示了一家大型 AI 公司如何借助 AI 完成大规模系统迁移，证明 LLM 生成的代码能在生产基础设施中带来切实的性能提升。它暗示了一种新范式：工程师负责架构和验证，AI 负责实现，这有可能降低采用 Rust 等性能关键型语言的门槛。 团队起步时没有任何 Rust 开发者，通过对照新旧系统的输出来验证迁移结果。瓶颈在于 CPU 而非 GPU，这促使团队决定放弃 Python。

telegram · zaihuapd · Oct 29, 03:13

**背景**: Anthropic 的 Messages API 是开发者与 Claude 模型交互的核心端点。Rust 是一种系统编程语言，以性能、内存安全和并发性著称，通过编译期的借用检查器强制执行，无需垃圾回收器。Python 虽然流行且适合快速开发，但由于解释器开销，在大规模场景下常成为 CPU 瓶颈。像 Claude 这样的 AI 辅助代码生成工具正越来越多地被用于在语言之间移植代码库。
