## [高盛限制 Claude Code 仅限工程师使用，银行家和交易员被移除访问权限](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers) ⭐️ 8.0/10

高盛已限制 Anthropic 的 Claude Code 和微软的 GitHub Copilot 仅限约 12,000 名工程师使用，并取消了银行家和交易员对这些 AI 编码工具的访问权限，而他们已使用这些工具数月。据彭博社报道，内部指导方针在 10 月经过生产力和风险审查后进行了更新。 此举凸显了在受监管的金融环境中部署 AI 编码代理的挑战，其中安全、合规和计费风险可能超过生产力提升。这可能预示着金融机构重新评估非工程人员使用 AI 工具权限的更广泛趋势。 高盛的“strats”小组——同时从事量化工作的软件工程师——保留访问权限，而交易员和银行家此前使用这些工具来跟踪客户资金流和构建市场模型。这一决定源于对 AI 代理在主工作站上访问敏感数据、电子邮件和互联网的“致命三角”风险的担忧。

hackernews · TheWiggles · Nov 8, 18:16 · [社区讨论](https://news.ycombinator.com/item?id=50415628)

**背景**: Claude Code 是 Anthropic 的代理式编码工具，可以编辑文件、运行命令并协助软件开发。像 Claude Code 和 GitHub Copilot 这样的 AI 编码代理在企业中越来越受欢迎，但它们带来了数据泄露和未经授权访问等安全风险，尤其是在合规要求严格的金融领域。
