## [Claude AI Solves 25-Year-Old NIST ECDSA Curve Seed Mystery](https://www.anthropic.com/research/ecdsa-curve-origins) ⭐️ 9.0/10

Anthropic announced that its Claude AI model discovered the origins of the NIST elliptic curve seeds (P-192, P-224, P-256, P-384, and P-521) in under half an hour. The seeds were not generated by any hash algorithm as previously assumed, but were instead the output of the C library's lrand48 random-number generator seeded with Unix timestamps. This discovery resolves a 25-year-old cryptographic mystery and debunks long-standing conspiracy theories that the NSA deliberately inserted backdoors into NIST's standardized elliptic curves. It restores confidence in widely deployed ECDSA curves used across TLS, code signing, and countless security protocols worldwide. Claude found that the seeds were generated using lrand48 seeded with Unix timestamps, but the fifth binary seed B-163 remains unexplained—possibly due to a typo during publication. The discovery does not rule out the possibility that specific timestamps were searched to select curves with particular properties, since discarded candidates cannot be observed.

hackernews · ahlCVA · Oct 16, 18:55 · [Discussion](https://news.ycombinator.com/item?id=50122800)

**Background**: NIST published the P-192 through P-521 elliptic curves in FIPS 186-2 in 2000, specifying that arbitrary seeds should be hashed with SHA-1 to derive curve parameters. The provenance of these seeds was never disclosed, fueling decades of speculation about NSA influence. lrand48 is a standard C library pseudo-random number generator using a linear congruential algorithm with 48-bit integer arithmetic.

Choosing the right image format directly impacts web performance, bandwidth costs, and user experience. As AVIF gains browser support and JPEG XL struggles with adoption, this comparison helps developers make informed decisions about which format to ship. The comparison highlights that libjxl's maximum effort is extremely slow (9–46 seconds, 50–180x default) for only 2–7% smaller files on photos, while AVIF can produce 10x smaller files with good quality but may erase fine details like highlights. AVIF is an open, royalty-free format based on the AV1 video codec, offering 30–50% smaller files than JPEG with HDR and transparency support. Both aim to replace legacy formats for web delivery, but browser support and encoder maturity remain key differentiators.
