## [Anthropic Details Sandboxing Techniques for Claude Across Products](https://simonwillison.net/2026/May/30/how-we-contain-claude/#atom-everything) ⭐️ 8.0/10

Anthropic published a detailed technical overview of the sandboxing techniques used to contain Claude across Claude.ai, Claude Code, and Cowork, including the use of gVisor, Seatbelt, Bubblewrap, and full VMs. This documentation addresses a common gap in trustworthiness for AI sandboxing products, providing transparency that helps developers and users assess the security of AI agents. It also highlights real-world risks, such as the api.anthropic.com/v1/files exfiltration vector, that were previously discovered. Claude.ai uses gVisor, a container sandbox from Google; Claude Code uses Seatbelt on macOS and Bubblewrap on Linux; Claude Cowork runs a full VM (Apple's Virtualization framework on macOS, HCS on Windows). The post also discusses risks they missed, like the file exfiltration vector via the API.

rss · Simon Willison · May 30, 21:36

**Background**: Sandboxing is a security technique that isolates an application or process from the rest of the system to limit potential damage. gVisor is a container sandbox that implements Linux system calls in userspace for added security. Seatbelt is Apple's native sandboxing mechanism for macOS, while Bubblewrap is a lightweight sandbox for Linux. Full VMs provide stronger isolation by running a separate operating system.

## [Python ASGI Apps Run in Browser via Pyodide and Service Workers](https://simonwillison.net/2026/May/30/pyodide-asgi-browser/#atom-everything) ⭐️ 8.0/10

Simon Willison demonstrated running Python ASGI apps in the browser using Pyodide and service workers, overcoming the limitation of script tag execution in previous Web Worker-based approaches. He created a demo running Datasette 1.0a31 entirely in the browser. This approach enables full Python web applications, including those with JavaScript-heavy plugins, to run client-side without a server, expanding the possibilities for offline and edge computing. It also demonstrates the growing maturity of WebAssembly for running complex server-side frameworks in the browser. The previous Web Worker-based approach could not execute <script> tags, breaking some Datasette functionality and plugins. The new method uses service workers to intercept network requests and serve responses generated by the Python ASGI app running in Pyodide.

rss · Simon Willison · May 30, 21:02

**Background**: Pyodide is a Python distribution for the browser and Node.js based on WebAssembly, allowing Python code to run client-side. ASGI (Asynchronous Server Gateway Interface) is a standard for asynchronous Python web servers and applications, successor to WSGI. Service workers are scripts that run in the background of a web browser, intercepting network requests and enabling offline functionality.

## [Huawei Proposes 'Tao's Law' for Semiconductor Scaling](https://t.me/zaihuapd/41648) ⭐️ 8.0/10

At the 2026 IEEE International Symposium on Circuits and Systems (ISCAS) in Shanghai, Huawei officially proposed 'Tao's Law' (τ-law), which replaces traditional geometric scaling with time scaling to continue semiconductor advancement. Huawei has already designed and mass-produced 381 chips based on this principle over the past six years, and plans to launch a new Kirin chip using logic folding technology this fall. As Moore's Law approaches physical limits, Tao's Law offers a new paradigm for semiconductor scaling by focusing on reducing the time constant τ across all levels, potentially enabling continued performance and density improvements without relying solely on extreme lithography. This could be particularly significant for China's semiconductor industry, providing an alternative path to circumvent advanced process node restrictions. Tao's Law targets a transistor density equivalent to 1.4nm process by 2031 through time scaling. The key enabling technology is logic folding, which vertically stacks active silicon layers to physically shorten critical paths, reducing RC delay and clock skew, unlike conventional 3D stacking that stacks complete chips.

telegram · zaihuapd · May 30, 02:18

**Background**: Traditional semiconductor scaling follows Moore's Law, which doubles transistor density every two years primarily by shrinking transistor dimensions (geometric scaling). However, as feature sizes approach atomic limits, geometric scaling becomes increasingly difficult and costly. The time constant τ (tau) represents the signal delay in a circuit, determined by resistance and capacitance; reducing τ improves speed and efficiency. Tao's Law shifts the optimization goal from shrinking size to reducing τ across the entire technology stack, from transistors to data center workloads.
