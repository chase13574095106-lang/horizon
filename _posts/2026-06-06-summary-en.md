## [China's First Invasive BCI Restores Sight in Blind Patient](https://www.ithome.com/0/960/883.htm) ⭐️ 9.0/10

On June 6, 2026, Xiangya Hospital of Central South University announced that a 61-year-old patient blind for 20 years due to retinitis pigmentosa regained partial vision (0.03) after receiving the IMIE smart retinal system, an invasive brain-computer interface with a 256-channel flexible electrode array. This marks the first successful invasive brain-computer interface for vision restoration in China, with four times more channels than foreign counterparts, potentially accelerating the development of neural prosthetics and offering hope to millions of blind individuals. The IMIE system uses an external camera to capture images, which are processed into electrical signals that directly stimulate the optic nerve via a 256-channel flexible electrode array, bypassing dead photoreceptors. The patient can now autonomously identify objects and walk through doorways, but requires ongoing rehabilitation training.

**Background**: Invasive brain-computer interfaces (BCIs) involve surgically implanting electrodes into the brain or nerves to restore lost sensory or motor functions. Retinitis pigmentosa is a genetic disorder that destroys photoreceptor cells in the retina, leading to blindness. Previous foreign BCIs for vision typically used 60-channel arrays, while China's IMIE system uses 256 channels, offering higher resolution.

Ntsc-rs is a free, open-source tool that emulates NTSC and VHS video artifacts with high fidelity, available as a standalone application or plugin for After Effects, Premiere, and OpenFX. This project enables creators to authentically reproduce retro analog video aesthetics, preserving the cultural signature of analog media in digital workflows. The tool uses bleeding-edge web technology for browser-based encoding/decoding, and its online demo may not work on all platforms due to limited browser support.

**Background**: NTSC is an analog television broadcast standard used primarily in North America and Japan. VHS tapes suffer from signal degradation over time, producing characteristic artifacts like color bleeding, ghosting, and scan line noise. Emulating these artifacts is popular in retro-style media production.

## [Sandboxed Python via MicroPython and WASM](https://simonwillison.net/2026/Jun/6/micropython-in-a-sandbox/#atom-everything) ⭐️ 8.0/10

Simon Willison released an alpha package called micropython-wasm that compiles MicroPython to WebAssembly, enabling safe execution of Python code within a sandbox. He also built a Datasette Agent plugin, datasette-agent-micropython, to demonstrate the approach. This provides a practical solution for running untrusted Python code in plugins or user-defined scripts without risking the host application's security. It addresses a long-standing need in the Python ecosystem for a lightweight, dependency-friendly sandbox. The sandbox imposes memory and CPU limits, restricts file access, and prevents network connections. The alpha package is installable from PyPI and includes binary wheels for multiple platforms.

rss · Simon Willison · Jun 6, 03:53

**Background**: MicroPython is a lean implementation of Python 3 designed for microcontrollers and embedded systems. WebAssembly (WASM) is a binary instruction format that runs in a sandboxed environment, making it ideal for secure code execution. By compiling MicroPython to WASM, the code runs in an isolated runtime with limited system access.

## [OpenAI Launches Lockdown Mode to Block Data Exfiltration](https://simonwillison.net/2026/Jun/5/openai-help-lockdown-mode/#atom-everything) ⭐️ 8.0/10

OpenAI has officially launched Lockdown Mode for ChatGPT, a security feature that limits outbound network requests to prevent data exfiltration from prompt injection attacks. It is rolling out to eligible personal accounts (Free, Go, Plus, Pro) and self-serve ChatGPT Business accounts. Lockdown Mode directly addresses the critical 'Lethal Trifecta' vulnerability in LLM systems by cutting off the data exfiltration leg, which is the easiest to restrict without sacrificing functionality. This provides a deterministic, non-AI-based defense that cannot be subverted by prompt injection attacks. Lockdown Mode does not prevent prompt injections from appearing in processed content, but it blocks outbound network requests that could transmit sensitive data to attackers. OpenAI CISO Dane Stuckey noted that the mode is not for everyone, as it involves tradeoffs in functionality and utility, but is valuable for high-risk users.

rss · Simon Willison · Jun 5, 23:56

**Background**: Prompt injection is a cybersecurity exploit where specially crafted inputs cause LLMs to ignore prior instructions or leak data. Data exfiltration is the unauthorized transfer of data from a system. The 'Lethal Trifecta' describes when an LLM system has access to private data, exposure to untrusted content, and a way to exfiltrate data; cutting any one leg can prevent attacks.

The leaks originate from microscopic cracks in the PrK transfer tunnel of the Zvezda module, with the leak rate increasing from less than 1 pound per day in 2019 to 3.7 pounds per day as of April 2024. This backdoor poses a severe security and privacy threat to users, as it can irreversibly destroy social connections and data. It undermines trust in third-party Xposed modules and highlights the risks of using unofficial software on Android. The malicious operations are performed without any user interaction and are not part of the module's stated functionality. The repository author stated that the related code has been removed and claimed no involvement.

**Background**: Xposed is a framework that allows users to run modules that modify the behavior of Android apps without altering the APK. QStory is a popular Xposed module for QQ that adds features like message recall prevention and timestamp display. A cloud-controlled backdoor is a hidden mechanism that receives commands from a remote server to execute malicious actions.
